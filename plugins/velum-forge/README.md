# Velum Forge 3D Studio Plugin

Official **Velum Forge** bundle for Google Antigravity, Claude Code, Cursor, and Codex.

## Included Capabilities
- **Always-On Rules (`rules/AGENTS.md`):** Enforces real-world meter scale, BVH shell-clipping verification, 10-view automated QA (`0` errors, `0` warnings), Blender 5.2+ color-space/node-socket safety, `2048x2048` Cycles GPU PBR baking, and 4-tier `LOD0`–`LOD3` chains.
- **`velum-3d-workflow`:** Master 6-stage runbook for end-to-end game-ready 3D assets.
- **`velum-cad-brep`:** Precision OpenCascade `build123d` mechanical CAD hardware (`STEP` + watertight `1:1 m` `GLB`).
- **`velum-pbr-bake-lods`:** Cycles `OPTIX` `2048x2048` PBR texture baking (`Color`+AO, OpenGL `Normal`, `Roughness`, `Metalness`, `AO`, `ORM`), variant pipelines, and seam-locked LODs.
- **`velum-organic-species`:** Closed `S^2` manifold organic/creature/fish modeling, signed-volume outward normal enforcement, polar eye UVs, and analytical swim rigging.
